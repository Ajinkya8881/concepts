# Good Practices for Software Development

## Question 1: Which point(s) were new to you?

* The importance of over-communicating with the team, especially when facing delays or unexpected issues.
* Asking questions with proper context instead of simply saying that something is not working.
* Using tools like screenshots, screen recordings, and code snippets to explain problems clearly.
* Joining meetings a few minutes early to build better relationships with teammates.

## Question 2: Which area do you think you need to improve on? What are your ideas to make progress in that area?

### Area to Improve

* Communication and asking better questions when I get stuck.

### Ideas to Make Progress

* Clearly explain the problem and the steps I have already tried before asking for help.
* Share screenshots, error messages, or code snippets whenever needed.
* Give regular updates to the team about my progress and any blockers.
* Avoid spending too much time stuck on a problem before reaching out for help.
* Use team channels for communication so everyone stays informed.
